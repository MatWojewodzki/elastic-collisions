# elastic-collisions

Simulation of elastic collisions made in **Python** using **Pygame**.

## Installation

1. Clone the repository:

    ```bash
    git clone https://github.com/MatWojewodzki/elastic-collisions
    cd elastic-collisions
    ```

2. Create a virtual environment (recommended):

    On **Linux/MacOS**:
    ```bash
    python3 -m venv venv
    source venv/bin/activate
    ```
   
    On **Windows**:
    ```bash
    python -m venv venv
    venv\Scripts\activate
    ```

3. Install dependencies:

    ```bash
    pip install -r requirements.txt
    ```
   
## Usage

Run the main script:
```bash
python src/main.py
```

## Python version

This project was developed and tested using **Python 3.12**.
